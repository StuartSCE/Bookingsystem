# Roadmap

## Phase 1 — supplied in this repository

- White-label admin UI
- Enquiries, customers, bookings
- Contracts/online acceptance
- Invoices and payment records
- Calendar
- Services/packages
- Team/suppliers
- Email templates and automation configuration
- Reports
- Public enquiry form
- Public availability page
- Optional SMTP/Stripe hooks
- Static GitHub Pages mode + Node server mode

## Phase 2 — production automation

- Background scheduler/queue
- Automatic enquiry sequences
- Automatic deposit/final invoice creation rules
- Automatic invoice reminders
- Automatic post-event review request
- Email delivery log and retry handling
- PDF attachment generation

## Phase 3 — integrations

- Stripe webhooks + automatic reconciliation
- GoCardless / PayPal options
- Google Calendar and Outlook sync
- Gmail/SMTP inbox linking
- Zapier/Make/webhooks
- Xero/QuickBooks export

## Phase 4 — agency / multi-user

- Staff logins + roles
- Per-user calendars
- Supplier contract workflow
- Supplier invoice/payment tracking
- Multi-brand organisations
- Separate client and supplier portals
- Fine-grained permissions and audit trail

## Phase 5 — commercial SaaS (if desired)

- PostgreSQL multi-tenant data model
- subscription billing
- tenant onboarding
- custom domains
- object storage
- automated backups
- observability and rate limiting
